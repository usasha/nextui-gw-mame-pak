# Optional case artwork

MAME artwork zips (`gnw_ball.zip`, `gnw_mariocm.zip`, ...) placed here are
uploaded by `deploy.sh` to `.userdata/tg5040/mame/artwork/` on the device.
The zips are not distributed via git (large binaries, and they are MAME
freely-redistributable artwork — grab them from a MAME artwork set).
Not shipped in the .pakz release; the stock `-view Internal` (LCD only)
needs no artwork.
